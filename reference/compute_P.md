# Count model effects

`compute_P()` returns the total number of effects in a choice model.

## Usage

``` r
compute_P(choice_effects)
```

## Arguments

- choice_effects:

  \[`choice_effects`\]  
  A
  [`choice_effects`](https://loelschlaeger.de/choicedata/reference/choice_effects.md)
  object.

## Value

An integer with the number of model effects.
