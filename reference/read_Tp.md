# Read `Tp`

This helper function reads the number of choice occasions `Tp` from a
[`choice_identifiers`](https://loelschlaeger.de/choicedata/reference/choice_identifiers.md)
object.

## Usage

``` r
read_Tp(choice_identifiers)
```

## Arguments

- choice_identifiers:

  \[`choice_identifiers`\]  
  A
  [`choice_identifiers`](https://loelschlaeger.de/choicedata/reference/choice_identifiers.md)
  object.

## Value

An `integer` `vector` of length `N`, where `N` is the number of
deciders.
